# Roadmap

最終更新: 2026-07-26

公開済み商品はiPhone / iPad `1.0.0`。`main` はiOS `1.1.0`の提出前候補。公開済みタグを動かさず、各版を1つの検証可能な目的へ絞る。

## v1.1 — 平時から緊急まで（提出前候補）

- 新ホーム、6つの緊急ショートカット、3項目の準備チェック
- 買い物リストを備えへ統合
- 記事の重複表示削減と関連導線
- v1.0データ互換、プライバシー境界、オフライン動作を維持

完了条件は [`V1_1_PRODUCT_PLAN.md`](./V1_1_PRODUCT_PLAN.md) を正とする。

## v1.2候補 — 継続して備える

- 明示許可制のローカル備蓄見直しリマインダー
- 個人情報を含まないホーム画面ウィジェットとApp Shortcut
- 子ども・高齢者・ペットを追加記事や絞り込みとして扱う
- v1.1の少人数観察テストとサポート経由の声から、実証された離脱点だけを修正

数量根拠のない家庭属性別の自動配分は行わない。通知権限は機能利用時に説明し、起動直後に要求しない。

## v1.3候補 — コンテンツと品質運用

- 記事・出典の鮮度台帳と開発者向け期限警告
- 火災、火山灰、車内避難など、一次情報と編集レビューを揃えられる記事
- ウィジェットから状況別記事へ進む安全なディープリンク
- 実機アクセシビリティ回帰確認の定例化

追加記事は `approved` 条件と `content-lint --distribution` を弱めない。

## v2以降の研究課題

- 署名付きコンテンツ更新
- 家族間共有、iCloud同期、端末間バックアップ
- オフライン地図や避難所データ
- Apple Watch、ロック画面表示、ライブアクティビティ

個人情報、鮮度、誤誘導、通信障害時の失敗を個別に脅威評価してから判断する。リアルタイム警報・ニュース・行政システムの代替にはしない。

## 継続して対象外

- アカウント必須化、広告、行動解析、SNS
- 専門的な医療診断
- 根拠のない備蓄数量や品目別個数の自動提案
- v1.1と同じ商品ページへのMac版追加
