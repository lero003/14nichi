# v1.1 Product Plan

最終更新: 2026-10-27
状態: **機能スライス実装済み・未提出のためv1.2候補へ統合**
対象: iPhone / iPad、`1.2.0` / ビルド `7`（本書は旧v1.1機能スライスの判断記録）

## 目的

初めて使う人が、起動直後に「今の困りごと」と「平時の準備」を区別できるようにする。緊急時は最優先記事へ1タップで進み、平時は人数・不足品・任意の緊急カードを短い一周で確認する。

## v1.1に含めるもの

- 初期タブをホームに変更し、6つの緊急ショートカットを配置
- 「3項目中○項目を確認」と表示する、非保証的な準備チェック
- タブを「ホーム / ガイド / 備え / 緊急 / その他」へ整理
- 買い物リストを「備え」の子画面へ統合
- 記事の重複H1を表示時だけ省略し、お気に入りをツールバーへ移動
- 同じ状況の確認済み関連記事を最大3件表示
- `PreparednessChecklistStore`には確認日時とカードの選択状態だけを保存
- v1.0の備蓄V2・緊急カードV1・お気に入り・読みやすさを無変更で継承

## 境界

- 準備チェックは安全度・防災力・充足率を採点しない。
- 緊急カード本文をホームから読まず、個人情報を進捗・ログ・エラーへ出さない。
- 数量入力は復活させない。自動計算は公的一次情報で数量根拠がある3項目だけ。
- アカウント、解析、広告、位置情報、リアルタイム警報、常時通信を追加しない。
- Macターゲットは残すが、統合先のv1.2公開・検証対象に含めない。

## リリース条件

- 6つのショートカットが `approved` / `immediate` 記事へ解決される。`shortcutArticleID` 指定時はその記事を優先し、未指定なら `critical` / `immediate` の先頭記事へフォールバックする。
- 機内モード相当で地震の最初の行動へ1タップ・30秒以内に到達できる。
- SwiftPMテスト、content-lint通常/配布、iOS Debug/Release build、UIテストが成功する。
- VoiceOver、最大級Dynamic Type、Reduce Motion、ダークモード、iPhone/iPadを実機または対象シミュレータで確認する。
- 緊急カードの認証・App Switcher秘匿・PDF共有を実機で再確認する。
- 初見利用者5人中4人が目的を10秒以内に説明し、準備3項目を10分以内に一周できるか観察する。この人間テストはコードの自動検証とは別に記録する。

## 非目標

通知、ウィジェット、家族共有、iCloud同期、署名付きコンテンツ更新、オフライン地図、Apple Watchは [`ROADMAP.md`](./ROADMAP.md) へ送る。
