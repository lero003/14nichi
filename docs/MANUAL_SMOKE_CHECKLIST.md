# v1.2 手動スモーク手順

最終更新: 2026-10-27
対象ビルド: マーケティングバージョン `1.2.0` / ビルド `7`（iPhone / iPad）

自動テストを通したあとに、実機またはシミュレータで実施する。結果は実施日・端末・所要時間を記録する。

## 前提

- 同梱記事はすべて `approved`。専門資格監修や正確性保証ではなく、最新の公式情報と現場の指示を優先する。
- 機内モード相当でコールド起動できること（ガイド本文はオフライン）。
- 公式リンクはオンラインが必要。

## A. コールド起動と30秒到達（必須・実機）

1. アプリを完全終了する。
2. 機内モードをオンにする（または通信を切る）。
3. 起動し、「ホーム」が表示されるまで測る。
4. 「地震」ボタンを1回押し、記事の「最初の5分ですること」まで到達する。
5. **合格**: 起動開始から最初の行動確認まで **30秒以内**。
6. 記録欄: 端末 / OS / 所要秒 / 実施者 / 日付

## B. ガイド・探索

1. ホームの6ショートカットが、それぞれ該当する記事へ1タップで進む。「避難を考える」は持ち出し袋ではなく、避難するか留まるかの判断記事へ進む。
2. 「すべての状況」からガイドへ進み、状況切替で記事一覧が変わる。状況名が見出しと重複しない。
3. ガイド先頭に検索欄が表示され、全文検索で本文ヒットする（例: `AED`）。
4. 検索結果・お気に入りに、記事が属する状況名が表示される。
5. カテゴリ・行動時期フィルタをかけ、解除できる。
6. ツールバーのお気に入り登録 → 絞り込み → 再起動後も残る。
7. 記事を開くと「記事の構成」が表示され、「最初の5分」「やってはいけない」などの見出しへ移動できる。
8. 状況一覧と記事詳細の右上から「読みやすさ」と「このアプリについて」を開ける。
9. 記事タイトルと同じ先頭H1が重複せず、短い注意と最初の行動が上部に見える。
10. 記事末尾に同じ状況の関連記事が最大3件表示され、開ける。
11. 記事詳細の「正式版」表示、本文後の詳細な限界説明、情報源、最終確認日、確認主体が表示される。
12. 情報源の公式リンクは機内モードでは開けず、オンラインではブラウザへ進む。
13. 「i」で開く画面に「14日ノートとは」があり、約2週間の暮らしを整えるオフライン行動帳だと分かる。

## C. 備蓄・買い物

1. 合計人数と計画日数だけを変更し、水・食料・携帯トイレの目安が即座に変わる。
2. 各品目に目安の出典・確認日と、オンラインで根拠を開く導線が表示される。
3. 家に足りない品目だけをチェックすると、直後に「買い物リストを見る」が表示される。
4. 買い物リストで「買った」を押すと、その品目だけが一覧から外れる。
5. 「不足品を見直す」で備えへ戻れ、購入済み表示になる。足りないチェックを外して再選択すると未購入へ戻る。
6. アプリ再起動後も人数・期間・不足選択・購入済み状態が残る。
7. 旧版で備蓄値を入力済みの場合、初回起動後も保存領域を開け、旧不足・準備済み状態が新しい選択へ反映される。
8. ホームと備えに同じ未購入件数が表示される。

## D. 平時の準備3項目

1. 初期状態は「3項目中0項目を確認」で、点数や安全保証の表現がない。
2. 家庭人数と期間を確認すると1項目、不足品を確認すると2項目へ進む。
3. 緊急カードを保存するか「今回は緊急カードを使わない」を明示すると3項目になる。
4. 緊急カード本文を入力済みでも、ホームには本文・氏名・連絡先が表示されない。
5. 各項目を再設定しても、備蓄・購入済み・お気に入り・カード本文が失われない。

## E. 緊急カード（個人情報）

1. 編集で連絡先・集合場所・アレルギー等を保存できる。
2. 文字数上限を超える入力が切り詰められる（または入力しにくい）。
3. 表示前認証をオンにすると、再表示に端末認証が必要。
4. 認証キャンセルで本文が漏れない。
5. ホームへ送って App Switcher で個人情報が平文で読めない（秘匿オーバーレイ）。
6. 「すべて削除」後、再起動しても内容が戻らない。
7. 備蓄・お気に入りが消えていない。

## F. 公式リンク集

1. 「その他」→「公式情報リンク集」。
2. オンライン接続が必要である旨が表示される。
3. 内閣府・気象庁など https の公的リンクが一覧される。
4. タップで外部ブラウザ/アプリが開く（通信境界はこの操作のみ）。

## G. PDF・印刷

1. 「その他」→「PDF・印刷」。
2. 既定では個人情報トグルがオフ。
3. 備蓄チェックリストのみ選択して生成できる。
4. 個人情報をオンにすると確認トグルなしでは生成できない。
5. 生成物のファイル名が `14nichi-export.pdf` 系で氏名を含まない。
6. 未選択項目の内容がPDFに出ない。
7. iPhone / iPad: 共有シートが開く。
8. 共有キャンセル後もアプリが落ちない。一時ファイルが残らない（可能なら確認）。

## I. 失敗系

1. 空の緊急カードでもクラッシュしない。
2. PDFで項目未選択時は生成されない。
3. 備蓄保存領域が壊れている想定は自動テスト側。手動では保存エラー表示があれば記録。

## 合否

- A〜G が重大不具合なく通る。
- A の30秒が実機で記録済み。
- H は内部TestFlight前に可能な範囲で記録し、未実施は明示する。
