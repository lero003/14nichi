# Roadmap

最終更新: 2026-10-27

公開済み商品はiPhone / iPad `1.0.0`。`main` はiOS `1.2.0`の提出前候補。未提出のv1.1機能スライスを引き継ぎ、2026-08-14の同梱記事・出典更新と2026-10-27の防災ガイド改善を一緒に提出する。公開済みタグを動かさず、各版を1つの検証可能な目的へ絞る。

## v1.2 — 平時から緊急まで＋内容鮮度更新（提出前候補）

- 新ホーム、6つの緊急ショートカット、3項目の準備チェック
- 買い物リストを備えへ統合
- 記事の重複表示削減と関連導線
- ガイド検索の常時表示、記事内見出しジャンプ、状況・記事一覧からの読みやすさ導線
- 避難ショートカットの遷移先を判断記事へ固定（`shortcutArticleID`）
- 水害・避難・余震・低体温の記事と、公的一次情報URLの再確認
- v1.0データ互換、プライバシー境界、オフライン動作を維持

機能面の完了条件は [`V1_1_PRODUCT_PLAN.md`](./V1_1_PRODUCT_PLAN.md)、提出手順は [`RELEASE_SUBMISSION_CHECKLIST.md`](./RELEASE_SUBMISSION_CHECKLIST.md) を正とする。

## v1.3候補 — 継続して備える

- 明示許可制のローカル備蓄見直しリマインダー
- 個人情報を含まないホーム画面ウィジェットとApp Shortcut
- 子ども・高齢者・ペットを追加記事や絞り込みとして扱う
- v1.2の少人数観察テストとサポート経由の声から、実証された離脱点だけを修正

数量根拠のない家庭属性別の自動配分は行わない。通知権限は機能利用時に説明し、起動直後に要求しない。

## v1.4候補 — コンテンツと品質運用

- 記事・出典の鮮度台帳と開発者向け期限警告
- 火災、火山灰、車内避難など、一次情報と編集レビューを揃えられる記事
- ウィジェットから状況別記事へ進む安全なディープリンク
- 実機アクセシビリティ回帰確認の定例化

追加記事は `approved` 条件と `content-lint --distribution` を弱めない。

## v2以降の研究課題

- 署名付きコンテンツ更新
- 家族間共有、iCloud同期、端末間バックアップ
- オフライン地図や避難所データ
- Apple Watch、ロック画面表示、ライブアクティビティ

個人情報、鮮度、誤誘導、通信障害時の失敗を個別に脅威評価してから判断する。リアルタイム警報・ニュース・行政システムの代替にはしない。

## 継続して対象外

- アカウント必須化、広告、行動解析、SNS
- 専門的な医療診断
- 根拠のない備蓄数量や品目別個数の自動提案
- 現行iOS版と同じ商品ページへのMac版追加
